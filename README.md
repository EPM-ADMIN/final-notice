# Final Notice

An original scratch-and-survive horror game by Endlesspixel Media. Work the night shift in a haunted debt office. Scratch connected routes to uncover payouts. Bank the money to pay your bills, or sacrifice the claim to send a false echo down a hallway and push the collectors back.

**[Play in your browser](https://epm-admin.github.io/final-notice/)** · **[All playable versions](https://epm-admin.github.io/final-notice/versions.html)** · **[Windows downloads](https://github.com/EPM-ADMIN/final-notice/releases)**

## v0.1.0 — First Night

This first playable prototype contains three 90-second shifts, escalating bills ($240 / $700 / $1,400), two approaching collectors, six possible between-shift benefits, procedural sound, two difficulty settings, and distinct success/failure endings. High scores save locally. A full Standard run takes about five minutes.

### Controls

| Action | Control |
|---|---|
| Scratch a seal | Press and drag / hold the pointer on the seal |
| Continue a route | Scratch an unrevealed seal directly above, below, left, or right of the last seal |
| Keyboard scratching | Arrow keys to select, Enter to reveal |
| Bank the whole claim | F or Bank Claim |
| Burn the claim into the west/east hall | Q / E or Echo West / Echo East |
| Route scratching through a hall | A / D or click a camera |
| Reduce room noise | Hold Space or Hold Your Breath |
| Pause / help | Escape / ? |
| Desktop fullscreen | F11 |

Echoes need a claim worth at least $12 and consume the whole unbanked claim. They never spend banked money. Collectors still approach while you are quiet. Cover the bill **and survive until the end of the shift**; unbanked money does not count. Surplus carries into the next shift. The game pauses when it loses focus.

### Windows

Download the Windows x64 ZIP from a release, extract the entire folder, and open **Final Notice.exe**. Keep the runtime files beside the executable. No installation, Node.js, or internet is needed. Windows 10/11 x64 are the supported targets. The prototype is not code-signed.

The desktop high-score profile is stored under `%APPDATA%/FinalNotice`, outside version-specific installation folders, so replacing the game folder does not erase it. Browser high scores are local to that browser/site and do not sync to the desktop app. Runs themselves are not saved midway.

The standalone HTML asset also works offline: download it and open it in a modern browser.

## Development

The game uses plain JavaScript, HTML Canvas, and Web Audio. Electron supplies the optional Windows shell. There are no game-package dependencies and no analytics or remote game services.

```sh
node --test tests/engine.test.cjs
node scripts/build.cjs
node scripts/package-windows.cjs
```

Use Node.js 22 or newer. Windows packaging runs on Windows x64 and downloads a pinned official Electron archive, verified against its SHA-256. An existing verified archive can be supplied using `ELECTRON_ARCHIVE`. The game lives in `src/`; the self-contained browser build is `dist/index.html`.

## Version preservation

Every release must have all four:

1. An annotated Git tag, `vX.Y.Z`, pointing to its tested source commit.
2. A GitHub Release with the versioned Windows ZIP, offline HTML, and SHA-256 checksums.
3. An unchanged browser copy at `docs/versions/vX.Y.Z/index.html`.
4. An entry in `docs/versions.json` and `CHANGELOG.md`.

Run `node scripts/build.cjs --archive` for a new version. The script refuses to replace an archived version with different bytes. The top-level browser page points to the current build; the archive keeps previous builds accessible. Never move an existing release tag or replace its downloads. Publish a new patch version for a fix. Keep local release ZIPs as an additional backup. Git history preserves source changes between releases.

## Credits and inspiration

The scratch/reward rhythm was inspired by [Scritchy Scratchy](https://store.steampowered.com/app/3948120/Scritchy_Scratchy/); the payment/upgrade cadence by [Bills Must Be Paid](https://rikegames.itch.io/bills-must-be-paid); and the camera/attention pressure by [Five Nights at Freddy's](https://store.steampowered.com/app/319510/Five_Nights_at_Freddys/). No assets, characters, story, or source code from those games are included. This is an independent project and is not affiliated with their creators.

The office background is original AI-generated artwork. Camera scenes, foil scratching, interface, and audio are generated by the game's code. Electron's license and third-party notices are included in the Windows distribution.

### Browser QA

Optional UI checks use Playwright 1.62.1 and an installed Edge browser. Install Playwright in your development environment (or set `PLAYWRIGHT_MODULE` to an existing installation). Run `node scripts/serve.cjs` in one terminal, then `node tests/browser-check.cjs` and `node tests/browser-run.cjs` in another. The full-run test uses real game controls and accelerates only the clock. Set `GAME_URL` to test a deployed build and `BROWSER_CHANNEL` to select another installed Chromium browser. Reports go to ignored `tests/artifacts/`.
